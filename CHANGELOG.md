# Changelog

## 0.0.1 alpha

First public release.

- Native stereo 3D (beta), optional AFR
- 6DoF head tracking
- 6DoF motion controls: aim, shoot, manual reload, melee, driving
- Hand poses and arm IK
- VR-adapted HUD (map on the wrist), cutscenes and menus in flat mode
- Driving system (steering wheel, lockpick, radio, horn)
- Weapon switching by gestures
- OpenXR / SteamVR support (tested on Quest 2)
- FXAA (beta)
- Installer that detects the game folder, copies the files, applies the patch and creates a desktop shortcut
